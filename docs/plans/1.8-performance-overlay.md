### 0A. Premise

- **Real problem:** from Phase 2 on, every step's "Done when" is a budget number (draw calls, fps, material count: `docs/PLAN.md:126,151,175,191`). The builder needs to see those numbers live while working, and e2e needs them as data. Without an overlay, every budget check is a manual DevTools session.
- **Target outcome:** press one key, see fps, frame time, draw calls, triangles, geometries, textures and JS heap; press again, it is gone. e2e reads the same counters through `rendererInfo()`.
- **Do-nothing cost:** low today (empty scene), rising in Phase 2 when 2.2, 2.5, 2.7 and 2.10 each need draw-call readings.
- **Proxy check:** the e2e half is already solved by 1.3. The task's real remaining delta is the visible overlay and its toggle. The "numeric counts" criterion is a proxy that zeros satisfy; it needs one non-empty draw to mean anything (addressed by E1, approved).
