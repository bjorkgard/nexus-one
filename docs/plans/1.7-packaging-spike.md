Question: D1 — D1: How should the packaged app load the built UI (#92)?
Project: nexus-one, task 1.7 on `feat/7-packaging-spike`.
ELI10: The app's window has to open the built web page. Opening it as a plain file gives the page no real web address, and the built page points at its scripts with addresses that break as plain files. A small custom address scheme (`app://`) fixes that, and Phase 8 already plans one.
Stakes: Pick wrong and either the spike fails for a reason unrelated to packaging, or Phase 8 rewrites the loader and the WebSocket Origin check (#94) has no origin to allow.
Recommendation: B, because 8.1 needs `app://` anyway and #94's Origin allowlist cannot allow a null `file://` origin; the cost now is about 30 lines plus a traversal test, and it removes `base: './'`.
Completeness: A 6/10 (happy path only if `file://` works), B 9/10 (real origin, no port, traversal tested), C 6/10 (works but adds a port and a server).
Net: B costs one small handler now and saves a loader rewrite in 8.1.
Header: Load path
A) Plan as written: file:// first
Keep `base: './'` and `loadFile('dist/index.html')`; check the renderer console and switch to `app://` only if module loads fail. Effort S, risk medium, reuses the plan text, verified by the console check only. ✅ Smallest change; follows #92's own "try first" context. ✅ Tests whether the inference in #92 is true. ❌ Leaves a null origin that #94's Origin allowlist cannot allow, so 8.1 rewrites the loader anyway.
B) app:// via protocol.handle (recommended)
Register a privileged `app` scheme, serve `dist/` through `protocol.handle` with a path-traversal guard, and load `app://nexus/index.html`; drop `base: './'`. Effort S, risk low, reuses the 8.1 design, verified by a traversal unit test plus the packaged-app check. ✅ Gives the page a real origin for CSP (8.2) and the WebSocket Origin check (#94). ✅ No listening port, so the Done-when lsof check stays meaningful. ❌ Pulls a slice of 8.1 forward and needs its own traversal test.
C) Loopback HTTP server
Serve `dist/` from a Node `http` server on 127.0.0.1 and load that URL. Effort M, risk high, no reuse from the plan, verified by an HTTP test. ✅ Plain HTTP origin, no Electron protocol API. ✅ Same code could serve a browser. ❌ Opens a port any local process or web page can reach, which the Done-when and #94 both work against.

   - host other than `nexus` → `null`
