## Working plan (accepted scope)

1. **Allocator** `src/world/desks.ts` (A1): seat list derived from `layout.deskSlots` (4 seats per cluster, fixed order: floor, slot index, seat index). `createDeskAllocator({ floors, seed })` (builds and memoises `buildLayout({ floors: n, seed })` for each floor count it reaches) with `allocate(agentId, parentId?)`, `release(agentId)`, `deskOf(agentId)`, `floorsNeeded`. Id hash: FNV-1a 32-bit over the UTF-16 code units of the id, mixed with `LAYOUT_SEED` through `hashSeed` (`src/world/rng.ts:20` takes numbers only, so the string hash is new and lives in `rng.ts` with its own test).
   - Input rules: an empty id throws `RangeError`; `parentId === agentId` is treated as a root; a parent counts only if it is already seated (`deskOf`), so cycles cannot form.
   - Root agent (OV1, D10; supersedes A1's root rule): try floors from the top office floor (`floorsNeeded - 1`) down to floor 1; on each floor start at `hash mod floorSeats` and linear probe within the floor to the first free seat (freed seats included); move down a floor only when it is full.
   - Subagent (OV7, D11): if the parent is seated and its floor has a free seat, probe outward from the parent's seat index within that floor (+1, -1, +2, -2, ...) to the nearest free seat; otherwise use the root rule. A parent that is not seated (unknown or released) means the root rule.
   - Order of preference: any free seat on existing floors (freed seats included) before growth. Growth only when every seat is taken: `floorsNeeded` rises by one and the agent takes a seat on the new top office floor (seats from `buildLayout({floors: floorsNeeded})`, lower floors unchanged per `layout.ts:735`). After growth the new top floor is tried first by later agents; a further floor is added only when every seat on every floor is taken. `floorsNeeded` is monotonic: it never shrinks when a grown floor empties (no rebuild churn; unit-tested).
   - Ceiling (C2, D8): when every seat on `MAX_FLOORS = 40` (`src/world/zones.ts:47`) floors is taken, `allocate` returns null and the agent stays unseated; the allocator exposes an `unseated` count (read by the `desks()` debug hook) and logs one `console.warn` per allocator.
   - Same id twice returns the same desk; `release` of an unknown id is a no-op.

Screens sit at the desk's inner edge facing their chair; `DeskSlot.facing` only fixes which pair is nearer the door (seat order: door side first, then run order).
